# ધ લેગસી · સત્સંગ યુનો બિંગો

ચોથી ગેમ (Beginning, Conclusion, Epilogue પછી). Node + Express + Socket.IO, બાકીની ગેમ જેવી જ રીતે Deploy થાય.

## Upload / Deploy
`server.js`, `host.html`, `player.html`, `package.json` (+ ઇચ્છો તો `questions-sample.txt`). Start: `npm start`.
Host: `/host.html` (ID `admin`, Password `gyan2026`; બદલવા માટે HOST_ID / HOST_PW environment variable).
Players: `/player.html?code=XXXXX` (QR પણ Host/Projector સ્ક્રીન પર આવે છે). બીજી સ્ક્રીન પર Projector: `/host.html?pj=XXXXX`.

## ગેમ કેવી રીતે ચાલે
- 4 ફેઝ (રંગ: ભક્તિ, જ્ઞાન, સેવા, સંસ્કાર — નામ Host બદલી શકે) × 9 પ્રશ્ન = 36 પ્રશ્ન.
- દરેક Player ને અલગ 5×5 કાર્ડ (કાર્ડમાં 25 જ જવાબ) + દરેક ખાનાનો રંગ + 5 યુનો કાર્ડ.
- પ્રશ્ન આવતા પહેલાં ફક્ત રંગ + નંબર દેખાય (પ્રશ્ન છુપો). પછી પ્રશ્ન, ખાનું દબાવો.
- સાચો જવાબ +1, ખોટું ખાનું −1, રંગ મેળ (ખાનાનો રંગ = પ્રશ્નનો ફેઝ રંગ) +1.
- યુનો કાર્ડ (દરેક એક જ વાર, એક પ્રશ્નમાં એક): વાઇલ્ડ (રંગ મેળ પાક્કો), +2 (સાચું +2 / ખોટું −2), રિવર્સ (એક વાર જવાબ બદલો), સ્કિપ (જવાબ આપ્યા પહેલાં; પ્રશ્ન ગણાય નહિ), સેવા (ઝોનના સાથીને +2 ભેટ).
- UNO!: કોઈ લાઇનમાં 4 ખાનાં થાય ત્યારે બટન. બોલ્યા પછી સાચો ક્લેમ → +2, ખોટો ક્લેમ → −2 (સામાન્ય ખોટો ક્લેમ −1). Projector પર નામ વગર "કોઈ UNO પર છે!".
- ક્લેમ: 1 લાઇન, 2 લાઇન, ફુલ હાઉસ. સાચું/ખોટું છેલ્લે Reveal પર જ ખૂલે.
- સંત પરિચય: ફોટો ધીમે ધીમે સ્પષ્ટ થાય; સાચો જવાબ પહેલા ત્રીજા ભાગમાં +3, પછી +2, પછી +1 (વધારાના).
- પ્રસંગ ક્રમ: 4 પ્રસંગ ગોઠવો; સાચો ક્રમ +2, સૌથી ઝડપી ત્રણને +3/+2/+1.
- મંદિર નિર્માણ: ઝોન દીઠ સરેરાશ (સાચા જવાબ + 4 × સાચા ક્લેમ). Projector પર ધુમ્મસમાં વધે, સાચા આંકડા Reveal પર.
- 108 માળા: સાચા જવાબ + 2 × સાચા ક્લેમ જેટલા મણકા; Player ના ફોનમાં જમા થાય, 108 પર બેજ.
- Reveal: 8 વિજેતા — 1 લાઇન, 2 લાઇન, ફુલ હાઉસ, ઝોન (સરેરાશ સ્કોર), મંદિર નિર્માણ, ત્રીજો, બીજો, ચેમ્પિયન.

## પ્રશ્નોનું ફોર્મેટ (Host બનાવતી વખતે ચોંટાડો)
```
સામાન્ય:      પ્રશ્ન::જવાબ
ફોટા સાથે:   [img:q1.jpg] પ્રશ્ન::જવાબ
સંત પરિચય:   [sant][img:sant1.jpg] આ સંત કોણ?::જવાબ
પ્રસંગ ક્રમ:  [kram] પ્રસંગોને ક્રમમાં ગોઠવો::પહેલો|બીજો|ત્રીજો|ચોથો     (સાચો ક્રમ લખો)
```
ફોટા `player.html`/`host.html` ની સાથે જ અપલોડ કરો. કાર્ડમાં સામાન્ય + સંત પ્રશ્નોના જવાબ (25 સુધી) આવે છે. `questions-sample.txt` માં નમૂનો છે (સરવાળા!) — તમારા સત્સંગના પ્રશ્નો ચોંટાડો.
